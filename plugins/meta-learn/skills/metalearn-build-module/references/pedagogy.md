# 交互教学设计指南

## 一、先建立内容连续性

先回答四个问题，再决定页面结构：

1. 学习者进入本模块时已经知道什么？
2. 本模块必须补上哪些时间、空间、人物、组织和事件？
3. 这些要素通过什么机制彼此连接？
4. 学完后，学习者应能对一份未见材料做出什么新判断？

不用并列的人名、年份和概念代替过程。每个关键节点至少要交代前因、当下改变和后续影响；无法确立单一因果时，展示多个条件如何共同作用。

## 二、控制抽象跃迁

一次主要教学动作只提升一层：

1. **看见**：让学习者从具体材料中找到人物、时空、差异或顺序。
2. **区分**：比较两个容易混淆的概念、状态或解释。
3. **连接**：把节点组成时间链、空间关系、组织结构或因果链。
4. **解释**：用自己的话说明为什么变化，并指出证据和限制。
5. **迁移**：将同一方法用到知识地图中未直接讲解的材料。

学习者在迁移任务中无法下手时，不重复抽象术语。先把原结论拆成“材料支持、材料反驳、材料不足”，再用两空或两句的最小任务启动。

主动回忆必须发生在知识刚形成连接之后，而不是全部集中到结尾：

- 每个主要学习阶段至少安排一次脱离正文的短输出，要求重建刚学到的关系，不只复述名词。
- 先输入或作答，再开放检查提示；直接展开参考答案属于复习材料，不算主动回忆。
- 输出长度和结构门槛由任务决定，不机械统一；完成判定至少检查基本长度或必要组成，不能只检查非空。
- 最终迁移只承担跨阶段整合，不重复收集本应在前面完成的全部局部输出。

## 三、补齐知识解释

对每个新概念或关键事件至少检查：

- 它具体指什么，不包括什么。
- 它出现前是什么状态，出现后改变了什么。
- 哪些人、政治组织、地区或社会群体参与其中。
- 它与前一单元和后一单元如何连接。
- 图示是关系模型、相对方位还是证据重建，哪些细节不可当真。

对初学者，不得用一组新术语解释另一个新术语。优先给出可追踪的人、组织、资源和行动。

## 四、根据关系选择表现形式

下列是选择线索，不是页面模板：

- 同时与先后：并行时间线、时间游标、阶段切换。
- 空间与层级：图层、相对方位、缩放尺度、中心—边缘强度。
- 政治组织与网络：节点—关系图、权力流、命令或资源路径。
- 因果与反馈：链条组装、条件开关、反事实比较。
- 证据与解释：证据阶梯、分类、信心等级、材料与结论对照。
- 分析单位与多视角：真正改变主图结构的视角切换，不只改变注释。
- 综合与迁移：陌生材料定位、案例重建、限定证据下的短分析。

若一种交互无法让核心关系变得比静态文字更清楚，删除交互，改用简洁图示或文字。

## 五、设计有信息的反馈

- 错误时指出错在时间、空间、分析单位、因果跳跃还是证据越界。
- 正确时说明该判断为什么成立，不只说“回答正确”。
- 永久进度只记录有意义的学习动作，不把滚动或装饰点击算作掌握。
- 参考答案用于显示思路和证据边界，不包装成唯一标准表述。

## 六、与理论目标保持距离

若知识地图的最终目标是理解某位作者或理论，先让学习者用历史材料建立独立判断。只在模块结尾标示已经能接近的理论问题，不用理论结论反向裁剪史实。
