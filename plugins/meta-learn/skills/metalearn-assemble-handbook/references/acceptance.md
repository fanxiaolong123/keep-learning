# 本地学习手册验收标准

## 1. 名称与课程边界

- 首页主标题与知识地图的规范名称一致。
- 作者、案例或学习目的只能作为副标题，不能替代课程名称。
- 入口和导航不改写教学正文、练习、答案、进度逻辑或本地存储键。
- 知识地图和模块数量、顺序与地图一致。

## 2. 入口与连续路径

- 入口页能在首屏说明“知识地图 + 全部模块”的关系。
- 知识地图是学习起点，模块按地图顺序排列。
- 六类目标均存在并正确：入口→知识地图、入口→各模块、每页→首页、每页→学习目录、相邻页面前进、相邻页面后退。
- 起点和终点不制造无意义循环。

## 3. 页面适配

- “首页”在桌面和手机端都能立即发现，带文字且触控区域至少 44×44 像素。
- 跨页导航不遮挡内部导航、保存失败提示、表单动作或安全区域。
- 固定页头在窄屏不会把进度、主题或重置控件挤出屏幕。
- 页面已有固定底栏时，不再叠加第二条固定底栏。
- 键盘用户可在正文前直达跨页导航，焦点轮廓清楚。

## 4. 本地运行

- 所有运行时脚本、样式和页面使用本地相对路径。
- 引用资料可以链接外部网站，但页面运行不依赖外部脚本、样式或字体。
- 入口和各页面可单独打开；文件名包含空格或中文时链接仍有效。
- macOS 启动器可执行，从自身目录解析入口；Chrome 不存在时能回退到默认浏览器。
